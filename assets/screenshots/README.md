# Homepage screenshot galleries

These are optimized web copies of the existing Desktop app assets, in their original numeric upload order. The source projects and exports are unchanged. Portrait artwork is fitted inside the showcase phone without cropping; game captures retain their original proportions.

| App               | Images | Source folder inside the Desktop app project                                                   |
| ----------------- | -----: | ---------------------------------------------------------------------------------------------- |
| VO2Cue            |      6 | `vo2cue/output/app-store-screenshots/final/iphone-1206x2622/`                                  |
| MyJourney         |      3 | `MyJourney/AppStoreScreenshots/final/iphone/`                                                  |
| Time Boxed        |      7 | `Time Box/output/App Store Screenshots/1242x2688/`                                             |
| My Fur Baby       |      8 | `MyFurBaby/output/app-store-2026-10-09/iphone/`                                                |
| Grave Maintenance |      4 | `GraveMaintenance/docs/`: `phone-portrait.jpg`, `ui-home.jpg`, `ui-trailer.jpg`, `ui-shop.jpg` |

Grave Maintenance uses browser-game captures; these are not described as App Store screenshots. Time Boxed’s provided storefront artwork contains illustrative UI, as documented by that project's screenshot README.

Web copies are WebP at quality 90, up to 828 pixels wide without enlarging small originals. All 28 images together are about 2.1 MB. Original titles and the image dimensions are listed with each app in the homepage’s `script.js`.
